# Ayham Bdair | Portfolio

A responsive personal portfolio showcasing my skills, projects, and interests in web development and cybersecurity.

## Features

- Responsive layout for desktop and mobile
- English and Arabic language switching
- Light and dark themes
- Project cards linked to GitHub repositories
- Contact information and social links
- Contact form that opens an email draft
- Saved language and theme preferences using localStorage

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project Structure

- index.html — Page structure and content
- style.css — Styling and responsive layout
- script.js — Language switching, themes, projects, and contact form
- assets/profile.jpg — Profile image

## Getting Started

Download or clone the repository, then open index.html in your browser.
